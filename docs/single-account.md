# Один счёт на 1000 ₽: историческая проверка

Дата: 30.10.2026. Статус: критерии пригодности не выполнены.

## Что реализовано

`server/src/backtest/single-account.ts` моделирует один общий счёт. Перед каждым
торговым периодом оценивает все 15 базовых стратегий проекта на BTC/USDT,
ETH/USDT, SOL/USDT и DOGE/USDT. Механизм выбора заменяет исходный мета-бот;
его доход не складывается с доходами отдельных стратегий.

Выбор использует только прошлые закрытые свечи. Требуются прибыль на обеих
частях обучения, превосходство удержания одного лота, минимум три закрытые
сделки и просадка обучения не выше 8%. Рейтинг: прибыль минус просадка.
Если кандидата нет, счёт остаётся в USDT.

Каждая стратегия ограничена одним минимальным лотом без усреднения.
Применяются комиссия 0,1% и проскальзывание 0,02% за сторону, шаг количества,
минимальный ордер и проверка остатка денег. Стоп позиции — 3% от цены входа.
Защита общего счёта — потеря 5% от максимума, после неё торговля прекращается.
Ценовые разрывы и проверка раз в час могут увеличить фактическую потерю.

При 1000 ₽ ставка 1% = 10 ₽ не соответствует минимуму большинства пар.
Вместо неисполняемых микросделок используется реальный минимальный ордер:
при минимуме 5 USDT это приблизительно 403 ₽. Такая позиция занимает около
40% исходного счёта. Плечо и реальные ордера отсутствуют.

## Как повторить

Из корня проекта:

```powershell
npm run single-account -w server
npm run typecheck
npm test
```

Команда скачивает публичную часовую историю Bybit за 30.10.2025–30.10.2026,
сохраняет её в `builds/single-bot-cache/` и затем использует тот же кэш.
Отчёт `builds/single-account-search-20261030.json` содержит правила лота,
SHA-256 данных, все девять попыток, выбранные параметры и критерии оценки.
Эти локальные файлы исключены из git существующим правилом `builds/`.

Разработка: 05.02–31.08.2026, начальный счёт каждой попытки — 1000 ₽.
Проверяются окна обучения 30/60/90 дней и торговли 7/14/30 дней.
Лучшее сочетание выбирается только по результату участка разработки.
Повторная проверка: 31.08–30.10.2026, отдельный исходный счёт 1000 ₽.
Это два самостоятельных испытания; их прибыли нельзя складывать как
доход одного непрерывного счёта. Повторная проверка не является независимой:
часть этого периода уже просматривалась в процессе исследования.

## Результаты

Предварительный выбор прошлого лидера без общей защиты счёта на участке
05.01–31.08 дал 779,87 ₽, потерю 220,13 ₽ и просадку 30,17%.
Предел потери от начального капитала сократил потерю до 51,06 ₽,
но не защитил накопленную прибыль. Поэтому добавлена защита от максимума.

к издержкам. Повышение издержек в этом прогоне исключило более слабого кандидата.

## Почему результат не принят

Одна закрытая сделка недостаточна для вывода об устойчивости. Минимальный
критерий эксперимента — десять операций в проверочном периоде; сам по себе
даже этот порог не доказывает преимущество. Доход ниже условного вклада 16%.
Восемь из девяти сочетаний окон убыточны на участке разработки.
Подбор параметров увеличивает вероятность случайно положительного результата.
Заявлять готовность к заработку или развёртывать этот вариант оснований нет.

## Границы модели

- Курс фиксирован: 80,5573 ₽/USDT. Рублёвая переоценка USDT не моделируется.
- Текущие правила лота применяются ко всей истории; исторические изменения неизвестны.
- Сигнал по закрытой свече, исполнение на открытии следующей часовой свечи.
- Просадка измеряется по открытиям/закрытиям; внутрисвечной минимум и ликвидность не моделируются.
- В конце каждого периода позиция закрывается по последнему закрытию с издержками.
- Обучение использует существующий `runBacktest`: открытый остаток оценивается
  по последнему закрытию без отдельной комиссии гипотетической ликвидации.
  В торговых периодах фактическая модельная ликвидация и её комиссия учитываются.
- После остановки защита не разрешает автоматический перезапуск.
- Для следующей версии нужен заранее зафиксированный алгоритм и новые данные,
  которые ещё не использовались при выборе правил.
